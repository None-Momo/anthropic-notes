# Effective Prompts

## What this section covers
- What makes a prompt effective
- Common patterns (role, task, constraints, examples, format)
- Iterating and refining with the model
- Guardrails and safety notes

## Quick start patterns
- **Role + Task**: “You are a reviewer. Summarize the key risks in &lt;text&gt;.”
- **Input + Output format**: “Given &lt;table&gt;, return JSON with fields ...”
- **Iterate**: “Draft → critique → improve” loop to raise quality.
- **Constraints**: word limits, style, tone, persona.

## Tips
- Be specific about goal, audience, and format.
- Give examples (few-shot) when consistency matters.
- Ask the model to state assumptions before finalizing.
- Use step-by-step reasoning when correctness matters.
